# GCalExtras

A Workspace Add-on for Google Calendar to improve productivity, brought to you by GCalTools.

GCalExtras integrates with Google Calendar to provide extras functionality: saving/loading groups of calendars, mass copy/edit/delete for a range of events with filters, easy access to the event location text, and storing private notes associated with individual events.

GCalExtras is free to use with a few limitations: a maximum of 3 presets can be created with the free version, events can be mass edited/moved in batches of 10 events, and private notes have a maximum length of 256 characters. 

Upgrading to the paid version removes these restrictions within a few minutes. Google enforces various quotas to which you will still be restricted, please see https://developers.google.com/apps-script/guides/services/quotas
